# Decoy IntelliJ plugin

Two Gradle modules, split deliberately by testability:

- **`core/`** — pure Kotlin, zero IntelliJ Platform SDK dependency.
  Audit log decrypt/read/write/clear, vault clear, override read/write,
  and the `PanelController` message-handling logic (mirrors
  `panelController.ts` in the VS Code extension exactly, including the
  "Clear All means ALL, including overrides" fix). Fully built and
  tested in this environment with real Gradle + JUnit 5 — see
  `core/build/test-results/` after running `./gradlew :core:test`.
  31 tests, all passing, as of this writing.

- **`plugin/`** — the thin IntelliJ Platform SDK wiring (ToolWindowFactory,
  Swing UI, `AnAction`s, `plugin.xml`). This module was **not compiled in
  this environment** — the IntelliJ Platform Gradle Plugin needs to
  resolve a full IDE distribution, which is a large download disproportionate
  to what compiling a thin wiring layer would prove. See
  `MANUAL_TEST.md` for exactly what needs a real IntelliJ instance to verify,
  and for which specific IntelliJ Platform API calls in this module are
  unverified judgment calls worth double-checking against real SDK docs
  or IDE code completion.

## Building

```bash
./gradlew :core:test        # fully works here; real tests, real Gradle
./gradlew :plugin:buildPlugin  # requires a real IntelliJ Platform SDK download -- untested in this environment
```

## Cross-language crypto

Both `core`'s audit log and vault readers use `com.macasaet.fernet:fernet-java8`
to stay wire-compatible with the Python service's `cryptography.fernet.Fernet`
encryption (see `../src/decoy/crypto.py`) and the VS Code extension's
`fernet` npm package (see `../vscode-extension/src/auditLog.ts`). This was
verified as real interop, not assumed: a genuine `cryptography.fernet`
token generated by Python decrypts correctly here (`CryptoTest.kt`), and a
token generated by this JVM code was independently confirmed to decrypt
correctly in Python during development (see the Phase 9 summary in the
conversation this was built from).
